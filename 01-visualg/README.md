# VisuAlg — pseudocódigo

Arquivos `.alg`. Abra no VisuAlg (Windows), em **Arquivo → Abrir**.

## Exemplos das aulas

| Arquivo | Assunto |
|---|---|
| `01_conversor.alg` | Entrada, cálculo e saída |
| `02_troco.alg` | Divisão inteira e resto |
| `03_desconto.alg` | Primeira condicional |
| `04_viagem.alg` | Condicionais encadeadas |
| `conta_de_luz.alg` | Faixas de valor com `senao se` |

## Para treinar

| Arquivo | O que fazer |
|---|---|
| `C1_teste_de_mesa.alg` | Faça o teste de mesa no papel antes de rodar. Depois rode e compare |
| `C2_com_erro.alg` | Tem um erro. Ache antes de executar |
| `bug1.alg` a `bug4.alg` | Um erro em cada. Dois são de lógica e não travam o programa, só dão resposta errada |

Nos arquivos de bug, resista à tentação de sair clicando em executar. O teste de mesa acha o erro mais rápido do que tentativa e erro, e é esse o hábito que a disciplina quer deixar em você.
