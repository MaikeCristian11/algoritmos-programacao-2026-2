# Python — condicionais e repetição

## Como rodar sem instalar nada

Os dois notebooks (`.ipynb`) abrem no Google Colab. Acesse [colab.research.google.com](https://colab.research.google.com), vá em **Upload** e escolha o arquivo. Funciona no navegador, inclusive no celular.

| Arquivo | Assunto |
|---|---|
| `Condicionais_em_Python.ipynb` | `if`, `elif`, `else` |
| `Repeticao_for_em_Python.ipynb` | `for`, `range`, acumuladores |
| `exemplos_condicionais.py` | Os mesmos exemplos em arquivo `.py` |

## Se quiser rodar na sua máquina

Instale o Python em [python.org/downloads](https://www.python.org/downloads/). Na instalação, marque a caixa **Add Python to PATH**. Depois:

```bash
python exemplos_condicionais.py
```

Quem já viu Java nas últimas aulas vai estranhar a volta ao Python. A sintaxe muda, o raciocínio não. Um `for` que soma continua somando igual nas duas linguagens.
