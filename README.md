## Como pegar o código

Se você já usa Git:

```bash
git clone https://github.com/MaikeCristian11/algoritmos-programacao-2026-2.git
```

Se não usa, clique no botão verde **Code** aqui em cima e depois em **Download ZIP**. Serve igual.

Vale aprender o `git clone` antes do fim do semestre. Quando eu corrigir algo ou adicionar um exemplo novo, quem clonou atualiza com um comando só:

```bash
git pull
```

Quem baixou o ZIP precisa baixar tudo de novo.
